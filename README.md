# ИИ-конструктор

Кликабельный прототип TravelLine по Figma: https://www.figma.com/design/oQw2hK8nCnK0ArdpYorVw3/?node-id=366-34818

React + @reactor/reactor. UI Kit: узел 288:12900. Все поля, кнопки, текст, пикеры, загрузчики и карточки используют Reactor. Палитра сайта содержит значения пользовательских данных из макета, а оформление интерфейса использует токены Reactor.

## Запуск

Node.js 22+ и доступ к корпоративному npm registry TravelLine. Положите утверждённый `.npmrc` в корень (он не входит в репозиторий).

```sh
npm ci
npm run dev
npm run build
```

Готовая автономная сборка — `index.html`. Её можно открыть напрямую в браузере или разместить на GitHub Pages из ветки main, папка / (root). Для разработки используется `development.html`; исходники — `main.tsx` и `styles.scss`. `npm run build` обновляет автономный HTML.

## Сценарий

Главная → данные объекта → дополнительные материалы (можно не заполнять) → оформление (брендбук, цвет, автоподбор) → демонстрационная генерация → редактор → список сайтов.

Дополнительное состояние неполных данных доступно по `?screen=data&state=missing`. Список сайтов появляется после демонстрационной генерации.

Файлы остаются в памяти браузера и не отправляются на сервер. После перезагрузки их нужно выбрать заново. Список созданных сайтов хранится в памяти до перезагрузки страницы. Каждое создание добавляет одну строку. Генерация и данные TravelLine имитируются. Редактор показан изображением из Figma с работающим возвратом «Мои сайты». Публикация и другие разделы ЛК не реализуют реальные операции.
